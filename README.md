# stroitelnaya-firma-idef-erwin
Комплексная модель работы строительной компании  Данный проект содержит разработку процессов и базы данных для строительной фирмы по дисциплине «Программная инженерия».  ## Состав проекта: * **AllProcess Modeler (BPwin)**, диаграммы процессов IDEF0 и IDEF3. * **ERwin Data Modeler**  * **Microsoft Access**
